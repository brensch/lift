- Updating the server no longer cuts off something you were in the middle of.
- Your program is now one document that plans every workout: how each lift progresses, warm-ups, rest, sets, plates, and your workouts. Settings → Program shows who set it and when, the ones before it, and a way back to the built-in rules.
- An AI assistant can set your program for you. Connect one at schlift.com/connect; it can read your training, try a program against your history, and set it. Revoke it any time from the same page or Settings → Program.
- Programs can add their own exercises, and progress lifts on fixed, linear, double, cycle or custom-formula rules as well as Schlift's own.
- Library workouts are now your own copies when you add them, so you can edit them freely.
- An assistant can try a program on any lifts you name, even before you've saved a workout.
- The developer sign-in turns down the same usernames that making an account does.
- An assistant changes your program with small edits instead of rewriting it, so it's much faster, and it can look up exercises and ready-made workouts.
- An assistant can give a lift its own numbers inside a shared progression (say, bigger jumps for legs), and can see how each lift has progressed over time.
